# Hades II Prometheus Flame Trainer

Статический фанатский тренажёр атаки Prometheus Flame Strike / Memory Flame из Hades II.

Неофициальный проект. Не связан с Supergiant Games.

## Что тренирует

- Запоминание safe-зон для варианта на 3 шага.
- Запоминание safe-зон для варианта на 5 шагов.
- Движение по круглой арене с наклонёнными полосами.
- Дэш на Space с короткой неуязвимостью.

## Открыть файлом

Открой `index.html` в браузере. Сборка и интернет не нужны.

## Управление

- WASD / стрелки: движение.
- Space: дэш.
- Enter или кнопка: старт раунда.
- `3 шага`: первая версия атаки.
- `5 шагов`: вторая версия атаки.

## Настройки

- Скорость волн.
- Скорость персонажа.
- Счёт успешных раундов, попаданий и лучшей серии.

## Локальная Wi-Fi сеть

Из этой папки можно запустить простой сервер:

```powershell
py -3.14 -m http.server 8080 --bind 0.0.0.0
```

IP компьютера:

```powershell
ipconfig
```

На другом устройстве в той же Wi-Fi сети открыть:

```text
http://<IPv4-компьютера>:8080/
```

Если Windows спросит про доступ через firewall, разрешить для частной сети.
